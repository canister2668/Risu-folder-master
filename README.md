# 📁 Risu 폴더 마스터 (Risu Folder Master)

RisuAI 봇 폴더를 한 화면에서 정리하는 플러그인(API v3)입니다. 왼쪽 캐릭터 사이드바를 여러 열로 펼치는 기능도 들어 있습니다.

- 설치 파일: [`dist/risu-folder-master.plugin.js`](dist/risu-folder-master.plugin.js)
- 업데이트 주소(공개판에만 들어감, `npm run release`): `https://raw.githubusercontent.com/canister2668/Risu-folder-master/main/dist/risu-folder-master.plugin.js`

## 설치

1. 위 설치 파일을 내려받습니다.
2. RisuAI 설정 › 플러그인에서 `+`를 눌러 파일을 고릅니다.
3. 옛 `📁 폴더 마스터 v3.07`이 있다면 지웁니다. 1.0.0은 이름이 `risu_folder_master`로 바뀌어 따로 설치됩니다.

공개판을 설치하면 RisuAI 플러그인 화면의 업데이트 확인이 이 저장소의 `main` 브랜치를 봅니다. 시험판(`npm run build`)에는 업데이트 주소가 없습니다.

## 기능

- **폴더가 주인공인 첫 화면**: "모든 폴더"에는 탐색기처럼 폴더 아이콘(개수 배지·이름)과 폴더 밖 봇만 보입니다. 아이콘을 누르면 그 폴더가 열리고, 폴더 안 화면의 폴더 아이콘·열린 폴더 다시 누르기·Esc로 돌아옵니다. 휴대폰은 한 줄에 4개이고, 위쪽 "폴더 목록"에서 폴더를 검색해 열 수 있습니다.
- **봇은 작게**: 아바타 34px 줄 칸. 보기는 칸·목록 두 가지.
- **검색**: 첫 화면에서는 폴더 이름이 맞으면 폴더 타일을, 봇 이름이 맞으면 폴더별로 봇을 보여 줍니다. 검색 결과에서 폴더를 열면 검색어가 비워집니다. 폴더 안에서는 그 폴더만 검색합니다.
- **고르고 옮기기**: 봇을 눌러 고르고(Shift로 범위, 키보드는 Space), 아래 막대에서 폴더로 옮기기·새 폴더·폴더 밖으로. 다른 폴더에서 고른 봇이 있으면 "다른 곳 N개"로 알려 주고, 개수를 누르면 어디서 골랐는지 보여 줍니다. 옮길 폴더 고르기 창에는 검색이 있고, 이미 들어 있는 폴더는 "현재 위치"로 막아 둡니다.
- **새 폴더**: "모든 폴더"의 「새 폴더」 → 이름 → 넣을 봇 고르기 → 「폴더 만들기」. 고른 봇이 있으면 바로 만듭니다(RisuAI는 빈 폴더를 지우므로 봇이 하나 이상 있어야 합니다).
- **폴더 관리**: 이름, 색(RisuAI 사이드바와 같은 8색), 그림, 위/아래, 폴더 삭제(봇은 폴더 밖으로). 휴대폰은 "더보기"에 모여 있고, 폴더 아이콘을 오른쪽 클릭(휴대폰은 길게 누르기)해도 같은 메뉴가 뜹니다.
- **폴더 그림**: 템플릿 24종(장르·형식·관리) 중에서 고르거나, 템플릿 종이에 폴더 이름을 새로 쓰거나(글씨 바꾸기), 내 그림(PNG·JPG·WebP)을 정사각으로 잘라 씁니다. 템플릿은 고를 때만 이 저장소의 `templates/`에서 받고, 저장된 그림은 RisuAI 에셋이라 플러그인을 지워도 남습니다.
- **사이드바에서 찾기**: 봇 칸의 ◎을 누르면 관리 화면이 닫히고 RisuAI 사이드바에서 그 봇에 테두리가 생깁니다(플러그인은 봇을 직접 열 수 없어서 위치를 알려 주는 방식입니다). 닫힌 폴더 안의 봇이면 폴더에 얇은 테두리가 생기고, 폴더를 열면 그 봇이 강조됩니다.
- **순서 편집**: 봇과 폴더를 끌어서 옮깁니다(키보드는 칸에 포커스를 두고 화살표). 끌고 있을 때 놓을 곳이 표시됩니다. 봇을 폴더 위에 놓으면 그 폴더로 들어갑니다. 휴대폰은 길게 눌러 끕니다. 저장하지 않고 닫거나 취소하면 먼저 묻습니다.
- **되돌리기**: 저장할 때마다 알림에 되돌리기 버튼이 뜹니다. 도구 메뉴와 Ctrl+Z로 최근 20개까지 되돌립니다.
- **정리 점검**: 같은 봇이 여러 자리에 있는지는 바로 확인합니다. 지워진 봇의 빈 자리·같은 이름은 모든 봇을 알아야 해서, 해적 RisuAI에서는 "전체 확인"을 따로 눌러 진행·중단할 수 있습니다.
- **사이드바 배열**: 사이드바를 2~5열로 펼칩니다. 항상 펼치기, 폴더를 열 때만 펼치기 중에서 고릅니다.

## 봇 정보 읽기

- 공식 RisuAI: 캐릭터 목록을 한 번에 읽습니다(메모리에 있어 빠름).
- 해적 RisuAI: 봇 하나를 읽을 때 그 봇의 채팅까지 함께 받으므로, 화면에 보이는 봇만 몇 개씩 읽고 이름·그림을 이 기기에 저장해 다음에 바로 그립니다. 읽기에 실패한 봇은 "읽기 실패 · 다시 읽기"로 표시됩니다.

## 사이드바 배열이 저장되는 방식

설정은 플러그인 저장소(서버 동기화)에 `risuFolderMaster.sidebarGrid`로 남습니다. 플러그인이 켜질 때마다 메인 화면 `<head>`에 별도 `<style>`을 넣습니다.

v3.07까지는 이 설정을 `customCSS`에 덧붙였습니다. 테마 프리셋 플러그인처럼 `customCSS`를 통째로 바꾸는 기능을 쓰면 그 블록이 함께 지워져, 새로고침 뒤 배열이 풀렸습니다. 1.0.0은 `customCSS`를 쓰지 않습니다. 관리 화면을 처음 열 때 옛 블록이 남아 있으면 새 저장소로 옮기고 `customCSS`에서 지웁니다.

메인 화면에 스타일을 넣으려면 RisuAI의 "메인 화면 접근" 권한이 필요합니다. 배열을 켠 경우에만 권한을 묻습니다. 플러그인을 끄거나 지우면 스타일도 빠집니다.

## 개발

번들러 없이 `src/`의 파일을 순서대로 이어 붙여 `dist/`를 만듭니다. Node 22가 필요합니다.

```sh
npm run build   # 시험판 dist (업데이트 주소 없음)
npm test        # 빌드 + 단위 테스트(node:test)
npm run ui      # 빌드 + 가짜 Risuai 화면 시험 + 공식판·해적판 사이드바 구조 시험 (Playwright 필요)
```

- `src/core/order.js`: characterOrder 순수 연산(옮기기, 폴더 만들기·삭제, 순서 편집 적용, 점검)
- `src/core/store.js`: 읽기·저장 대기열·되돌리기(쓰기 직전 재확인·쓴 뒤 확인), 아바타 캐시
- `src/core/roster.js`: 봇 이름·그림 읽기(공식판 전체 / 해적판 보이는 봇만 + 기기 저장, 판별 실패 시 아무것도 지우지 않음)
- `src/sidebar/grid.js`, `src/sidebar/locate.js`: 사이드바 배열·찾기(공식판·해적판 사이드바 구조 모두)
- `src/ui/*`: 화면, 대화상자, 끌어 옮기기
- `e2e/`: 실제 RisuAI 시험 서버용 Playwright 스크립트. 폴더 배치를 바꾸므로 로컬 시험 주소에서만 돌아가게 막혀 있습니다.

메인 화면에 넣는 CSS는 v3 `setInnerHTML`의 DOMPurify를 거칩니다. 그래서 `<`, `>`, `&`를 쓰면 안 됩니다(단위 테스트가 검사합니다).

**한계(동시 편집):** 플러그인 API에는 원자적 비교-쓰기가 없습니다. 저장은 쓰기 직전에 다시 읽어 그 사이 바뀌었으면 최신 값에 다시 적용하고, 쓴 뒤 다시 읽어 확인합니다. 하지만 마지막 읽기와 쓰기 사이의 아주 짧은 틈에 다른 기기·다른 플러그인이 폴더 배치를 바꾸면 그 변경은 덮어써지고 알아챌 수 없습니다. 폴더 마스터로 정리하는 동안에는 다른 곳에서 폴더 배치를 바꾸지 마세요. 예전 판의 customCSS 그리드 블록을 옮기는 일도 같은 한계가 있습니다.

## 배포

### 시험판(운영자 서버에서만 시험)

`npm test` → `npm run ui` → `python3 scripts/deploy-live.py`(드라이런) → `--apply`(같은 버전이면 `--replace-same-version`).
시험판에는 업데이트 주소가 없으므로 RisuAI가 GitHub 판을 업데이트로 안내하지 않습니다.

### 공개판(GitHub = 업데이트 서버)

RisuAI는 설치된 플러그인의 `//@update-url`에서 앞부분을 읽어 `//@version`을 비교합니다. 이 저장소의 `main`이 곧 업데이트 서버입니다.

1. `package.json`의 `version`을 **이미 공개된 최고 버전보다 높게** 올립니다(배포 뒤 고침은 셋째 자리만). `FM_LAST_PUBLIC=<공개된 버전> npm run release`로 검사합니다.
2. `npm test`, `npm run ui`를 통과시킵니다.
3. 마지막에 `npm run release`로 공개판을 빌드합니다(업데이트 주소를 넣고 버전을 검사).
4. `CHANGELOG.md`에 적고 `dist/`까지 함께 커밋해 `main`에 푸시한 뒤 태그·릴리스를 만듭니다.

`raw.githubusercontent.com`은 몇 분간 캐시하므로 바로 안 보일 수 있습니다.

## 폴더 그림 템플릿

- 원본은 `assets-src/`(512px PNG, 빈 종이판, `templates.json`=종이 위치)이고, `python3 scripts/build-templates.py`가 `templates/`(배포용 WebP·글꼴)와 `src/ui/templates-data.js`(목록·96px 섬네일)를 만듭니다.
- 글씨 글꼴은 [Black Han Sans](https://fonts.google.com/specimen/Black+Han+Sans)(SIL Open Font License 1.1, `templates/OFL.txt`)입니다.
- 템플릿 그림은 이 플러그인과 같은 GPL-3.0으로 배포합니다.
